# Fab Gym: the submission site

The one page judges land on: Lou Latency shows off his fab and its digital twin, and Meta's models do the work. The
code lives in [fab-gym](https://github.com/apoorvasinha183/fab-gym).

| File | What |
| --- | --- |
| `index.html` | The site, a single static page in Lou's voice. Pictures in `img/`. |
| `SCRIPT.md` | The three-minute video, beat by beat, for Lou to perform |
| `SUBMISSION.md` | The submission form's answers, a draft |

## Before it goes live

1. Upload the video to YouTube, then put its id in `data-youtube="..."` on the `#video` box in `index.html`.
2. Make this repository public (GitHub serves Pages from public repositories on the free plan).
3. Settings, Pages: deploy from the `main` branch, root folder. The site appears at
   `https://apoorvasinha183.github.io/fab-gym-site/`.

Lou Latency is a cartoon. His fab is the SMT2020 testbed (Kopp, Hassoun, Kalir and Mönch, IEEE TSM 2020); no real
fab's data.
